# TestSpace — платформа для онлайн-тестов и заданий по программированию

Веб-приложение: учитель создаёт группы, тесты и задачи с кодом, студенты выполняют их в полноэкранном режиме,
а «Монстр» ловит списывание (выход из полного экрана, смена вкладки, вставка текста).

## Как устроено теперь

Своего сервера больше нет (удалены Node.js, Express, Docker). Сайт — это обычные статические файлы, которые раздаёт **Vercel**,
а вся «серверная» работа выполняется в **Firebase**:

| Что | Где |
|---|---|
| Страницы и интерфейс | Vercel (папка `public/`) |
| Регистрация и вход | Firebase Authentication |
| База данных (группы, тесты, результаты) | Firebase Firestore |
| Кто что может читать и писать | `firestore.rules` (правила безопасности Firestore) |
| Проверка кода студентов | в браузере: JavaScript и Python |

Весь интерфейс и все возможности сайта остались прежними.

## Быстрый старт

1. Настройте Firebase (10 минут, один раз): **`docs/FIREBASE.md`**.
2. Вставьте ключи веб-приложения в `public/firebase-config.js`.
3. Загрузите проект на GitHub и подключите его в Vercel: **`docs/INSTRUKCIYA.md`**.

Проверить на своём компьютере (нужен только Python или Node.js, любой веб-сервер подойдёт):
```
cd public
python -m http.server 8000      # или: npx serve .
```
и откройте http://localhost:8000 (файл `index.html` двойным кликом не откроется: браузер не загружает модули с `file://`).

## Что умеет

* **Каталог** публичных заданий и вход в **приватное задание по коду**.
* Задания двух видов: **тест** (варианты ответа, можно с **фото**) и **задача с кодом** (Python, JavaScript; Java и C++ — с ручной проверкой учителем).
* Тёмная и светлая тема, языки RU / KZ / EN, профиль.
* **Учитель:** группы с паролем · исключение студентов · таймер на весь тест или на каждый вопрос · **срок сдачи** ·
  варианты (одинаковые / на выбор / у каждого свой) · скрытые тесты · онлайн-контроль нарушений · статистика · ручная доплата баллов.
* **Участник:** создаёт публичные или приватные (по коду) задания и проходит чужие.
* **Студент:** вступает в группу по названию и паролю · редактор кода с подсказками · запуск примеров.
* **Защита от списывания:** полный экран, смена вкладки, вставка/копирование, правая кнопка → Монстр. 3 предупреждения — работа сдаётся сама.

## Структура проекта

```
public/index.html        разметка и стили
public/app.js            весь интерфейс (страницы, редактор, Монстр)
public/i18n.js           переводы RU / KZ / EN
public/ts-api.js         «бэкенд в браузере»: все действия (вход, группы, тесты, проверка) поверх Firebase
public/firebase-init.js  подключение Firebase SDK
public/firebase-config.js  ВАШИ ключи Firebase (вставить один раз)
firestore.rules          правила безопасности базы (вставить в консоль Firebase)
vercel.json              настройки Vercel (папка public)
docs/                    инструкции и материалы для курсовой
```

## Что важно знать (ограничения без сервера)

* **Проверка работы выполняется в браузере студента.** Правила Firestore не дают студенту видеть верные ответы и скрытые тесты
  во время теста, не дают менять чужие данные и чужие результаты. Но результат своей работы записывает сам браузер,
  поэтому технически подготовленный студент может подделать собственную оценку, а после сдачи — прочитать ключи ответов.
  Для курсовой, колледжа и обычных контрольных этого достаточно; для серьёзных экзаменов нужна проверка на сервере
  (Firebase Cloud Functions, тариф Blaze, или API-функция Vercel) — это следующий шаг развития.
* **Java и C++** в браузере не запускаются (нет компилятора). Студент может писать такие решения, а учитель смотрит их и ставит баллы
  («Онлайн-контроль» → «Смотреть» → «Доплата баллов»). JavaScript и Python проверяются автоматически.
* **Python** при первом запуске загружается из интернета (~10 МБ, потом из кеша браузера).
* Бесплатный тариф Firebase (Spark): примерно 20 000 записей и 50 000 чтений в сутки. Для класса и курсовой хватает.
* Браузер не может на 100% запретить списывание (телефон, второй монитор). Монстр отслеживает нарушения внутри браузера.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| Красная полоса «Firebase не настроен» | вставьте ключи в `public/firebase-config.js` |
| «Включите Email/Password» при регистрации | Firebase → Authentication → Sign-in method → Email/Password → Enable |
| Регистрация проходит, но дальше ошибки; в консоли браузера (F12) `permission-denied` | не опубликованы правила: Firestore → Rules → вставьте `firestore.rules` → Publish |
| Страница белая при открытии двойным кликом | запускайте через веб-сервер (см. «Быстрый старт») или откройте сайт на Vercel |
| Python не запускается | нужен интернет для первой загрузки |
