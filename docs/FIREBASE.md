# Настройка Firebase (один раз, ~10 минут)

Firebase заменяет сервер: **Authentication** отвечает за вход, **Firestore** — за базу данных.
Сайт обращается к Firebase прямо из браузера, а защиту данных обеспечивают **правила** (`firestore.rules`).

## 1. Проект
Откройте https://console.firebase.google.com → войдите через Google → выберите ваш проект (или **Add project**; Analytics можно отключить).

## 2. Включите вход по логину и паролю
1. Слева **Build → Authentication → Get started**.
2. Вкладка **Sign-in method** → **Email/Password** → включите первый переключатель (Enable) → **Save**.

> Сайт сам превращает логин в служебный адрес вида `…@testspace.app`, настоящие e-mail пользователей не нужны.
> Логин может быть любым (хоть русским). Пароль от 4 символов, как и раньше.

## 3. База данных Firestore
1. **Build → Firestore Database → Create database** (если ещё нет).
2. Режим **Production mode**, регион ближайший (например, `europe-west3`). Регион потом не поменять.
3. Вкладка **Rules** → удалите всё, вставьте **весь** файл `firestore.rules` из проекта → **Publish**.
   Без этого шага сайт не будет работать (все запросы будут отклонены).

## 4. Ключи для сайта
1. ⚙ **Project settings → General → Your apps** → значок **`</>`** (Web) → имя любое → **Register app**
   (галочку Firebase Hosting не ставьте).
2. Появится объект `firebaseConfig`. Скопируйте его значения в файл **`public/firebase-config.js`**
   (`apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`).

Эти ключи **не секретные**, их можно выкладывать на GitHub и Vercel: данные защищены правилами, а не ключом.

## 5. Старый ключ сервера больше не нужен
Файл `serviceAccountKey.json` использовал только старый сервер. **Не загружайте его ни на GitHub, ни на Vercel.**
Если вы его кому-то отправляли (в чат, в архив), отзовите: Project settings → **Service accounts** →
**Manage service account permissions** → в Google Cloud откройте аккаунт `firebase-adminsdk…` → вкладка **Keys** → удалите ключ.

## 6. Проверка
Запустите сайт (`python -m http.server 8000` в папке `public`, адрес http://localhost:8000 или ваш адрес на Vercel),
зарегистрируйтесь. В Firebase Console → Firestore Database → Data появятся коллекции `users`, `groups`, `tests`, `attempts` и другие.

## Что где хранится
| Коллекция | Содержимое | Кто читает |
|---|---|---|
| `users` | имя, логин, роль | любой вошедший (имена нужны в списках), менять — только владелец |
| `groups`, `groupMembers` | группы и их участники | учитель-владелец и участники |
| `groupKeys` | хеш(название + пароль группы) → группа | по ключу целиком; пароль группы нигде не хранится |
| `tests` | карточка теста: название, срок, таймер (без вопросов) | все вошедшие (приватные в списки не попадают) |
| `testQuestions` | вопросы без ответов и без скрытых тестов | автор и те, кому тест доступен |
| `testSecrets` | верные ответы, скрытые тесты, код приватного теста | автор; студент — только после сдачи своей работы |
| `testCodes` | код приватного теста → тест | по коду целиком |
| `attempts` | ответы, нарушения, результат; id = `тест_студент` | студент (свои) и учитель-автор |
| `images` | фото к вопросам | вошедшие |

## Лимиты бесплатного тарифа (Spark)
Около 20 000 записей и 50 000 чтений в сутки (точные цифры: Firebase Console → Usage). Сайт экономит запросы:
ответы автосохраняются раз в 4 секунды и только если изменились, онлайн-контроль учителя работает через одну живую подписку.
